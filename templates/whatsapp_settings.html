إعدادات واتساب التلقائي

مهم: الإرسال التلقائي الحقيقي يحتاج رابط API من مزود واتساب رسمي مثل Meta WhatsApp Business API أو مزود محلي/خارجي. لا يكفي رابط wa.me للإرسال التلقائي، لأنه يفتح واتساب فقط ولا يرسل بدون تدخل.

شرح تركيب رابط واتساب API

اطلب من مزود خدمة واتساب رابط إرسال رسالة API. يجب أن يحتوي الرابط على مكان للرقم ومكان للرسالة.

https://provider.com/send?token=YOUR_TOKEN&phone={phone}&message={message}

النظام سيستبدل:
{phone} برقم العميل
{message} بنص الرسالة

مثال عملي

https://api.example.com/whatsapp/send?apikey=123456&to={phone}&text={message}

بعد الحفظ، أي رسالة مجدولة في صفحة واتساب سيتم إرسالها تلقائياً عند الموعد، وسيظهر تنبيه في صفحة التنبيهات بنجاح أو فشل الإرسال.
