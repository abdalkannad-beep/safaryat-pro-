
# نظام وكالة السفريات والسياحة - نسخة كاملة قابلة للتشغيل

## بيانات الدخول الافتراضية

### حساب المشرف الأعلى Super Admin
- المستخدم: `superadmin`
- كلمة المرور: `super123`

### حساب الأدمن
- المستخدم: `admin`
- كلمة المرور: `admin123`

## طريقة التشغيل
```bash
pip install -r requirements.txt
python app.py
```

ثم افتح:
```text
http://127.0.0.1:5000
```

## المميزات
- تسجيل دخول.
- حساب مشرف أعلى Super Admin فوق الأدمن.
- المشرف الأعلى ينشئ حسابات الأدمن ويتحكم بها.
- الأدمن ينشئ حسابات الموظفين فقط.
- حساب مدير وحسابات موظفين.
- إدارة العملاء والجوازات وأرقام الواتساب.
- إدارة الأصناف والأسعار من حساب المدير.
- إضافة معاملات: عمرة، حج، عمل، زيارة، زيارة عمل، تعديل مهنة، رخصة قيادة، أو أي صنف جديد.
- التفويض على المكتب.
- السداد والمدفوع والمتبقي.
- دفعات متعددة.
- مصروفات.
- تقارير يومية منفصلة.
- تنبيهات عند بلوغ المعاملة عدد أيام يحدده المدير.
- رسائل واتساب يدوية وروابط WhatsApp Web.
- حفظ رسائل مجدولة داخل النظام.

## ملاحظة مهمة عن واتساب
الإرسال التلقائي الحقيقي يحتاج ربط WhatsApp Business API من Meta أو مزود رسمي. هذه النسخة تحفظ الجدولة وتفتح رسائل يدوية عبر WhatsApp Web.

## تشغيل النظام على الهاتف

1. شغل النظام على الكمبيوتر:
```bash
python app.py
```

2. اعرف IP الكمبيوتر داخل الشبكة:
- في Windows افتح CMD واكتب:
```bash
ipconfig
```
خذ رقم IPv4 مثل:
```text
192.168.1.20
```

3. من الهاتف المتصل بنفس الواي فاي افتح:
```text
http://192.168.1.20:5000
```

## تشغيل سريع على Windows
اضغط مرتين على:
```text
run_windows.bat
```

- إرسال فوري عبر API.
- تنبيه داخل النظام عند نجاح أو فشل الإرسال.

### صيغة رابط API
ضع الرابط في:
```text
إعدادات واتساب > رابط API
```

مثال:
```text
https://provider.com/send?token=YOUR_TOKEN&phone={phone}&message={message}
```

النظام يستبدل:
```text
{phone} = رقم العميل
{message} = نص الرسالة
```

ملاحظة: رابط WhatsApp العادي wa.me لا يرسل تلقائياً بدون تدخل المستخدم. الإرسال التلقائي يحتاج مزود API رسمي.
